# Week 1 chromosome-22 training workflow

[Workflow contents](../README.md) · [Next: Consensus peaks and counting →](../week2_consensus_counts/README.md)

The original Week 1 work was performed interactively with command records and
validation evidence, rather than as one canonical public pipeline script. To
avoid presenting reconstructed commands as the exact executed workflow, this
release documents Week 1 in `docs/METHODS.md` and includes selected validated QC
figures only.

The sample was SRR7650763, an untreated Immature NK paired-end run restricted
to a GRCh38 chromosome-22 teaching subset. It was not included in the Mature
versus Memory differential-accessibility analysis.
