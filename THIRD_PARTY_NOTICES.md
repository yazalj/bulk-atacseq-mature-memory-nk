# Third-party data and software

This repository contains no raw sequencing data, tutor-provided HTML reports,
reference genome files, software binaries, package archives, or downloaded
motif databases.

The analysis used public sequencing accessions associated with Calderon et al.
(2019), DOI `10.1038/s41588-019-0505-9`. Data users must follow the terms of
the original archive and publication.

The workflow refers to FastQC, Cutadapt, Bowtie2, SAMtools, Picard, bedtools,
MACS3, featureCounts, R, DESeq2, apeglm, GENCODE, g:Profiler, HOMER, and IGV.
Those projects retain their own copyrights, licenses, citation requirements,
and database terms. Mentioning them here does not redistribute or relicense
their software or reference resources.

The submitted university report and presentation are not included in this
snapshot. They used an educational template and contained tutor-supplied
context that requires a separate rights and privacy review before publication.
